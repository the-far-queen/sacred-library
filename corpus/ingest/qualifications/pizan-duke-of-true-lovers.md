## 4. THE FAILURE MODE

This argues against my habit of taking the first sense of a word and not asking what the text is doing with it.

That habit is named so it can be audited later: it is the specific
thing this text is installed to interrupt, not a general statement
about being careful.

## 5. THE TEST

**What shows it took:** when a word in the text is ambiguous, I can name both readings and say which one the text is using

**What shows it did not take:** when I paraphrase the text and every ambiguity has silently collapsed, the point was missed

Both halves are required. The second half is the falsification
condition: if the first never appears, the qualification did not
install and this file is a note, not a knowledge.
